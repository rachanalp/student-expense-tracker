# 💰 Student Expense Tracker

A full-stack web application designed to help students track, manage and analyze their daily expenses.

## 🚀 Features

### Current Features
- Add expenses
- Edit expenses
- Delete expenses
- Search expenses
- Filter by category
- Sort expenses
- Set monthly budget
- Track total spending
- Track remaining budget
- Budget usage progress bar
- Expense statistics
- Category-wise expense chart
- Local storage support
- Responsive design

## 🛠️ Technologies

### Frontend
- HTML5
- CSS3
- JavaScript
- Chart.js

### Backend
- Java
- Spring Boot
- REST API

### Database
- MySQL

### Tools
- Git
- GitHub
- VS Code
