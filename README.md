# 💰 Student Expense Tracker

A full-stack web application designed to help students track, manage, and analyze their daily expenses.

## 📌 Project Overview

Student Expense Tracker is a web-based application that allows users to record expenses, manage a monthly budget, and analyze spending patterns through charts and statistics.

The project uses a Java Spring Boot backend with a MySQL database and a responsive HTML, CSS, and JavaScript frontend.

## 🚀 Features

- ➕ Add expenses
- ✏️ Edit expenses
- 🗑️ Delete expenses
- 🔍 Search expenses
- 🏷️ Filter expenses by category
- ↕️ Sort expenses
- 💰 Set monthly budget
- 📊 Track total spending
- 💵 Track remaining budget
- 📈 Budget usage progress bar
- 📊 Expense statistics
- 🥧 Category-wise expense chart
- 📅 Monthly expense analysis
- 📱 Responsive design
